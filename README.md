# FANET Research

Research on Flying Ad Hoc Networks (FANETs), focusing on routing stability, OLSR, and Multi-Point Relay (MPR) selection algorithms.

## Research Topics

- OLSR routing protocol
- MPR selection algorithms
- Link Expiration Time (LET)
- FANET topology changes
- Routing performance evaluation using ns-3

## Project Structure

- `simulations/` — ns-3 C++ simulation source code
- `scripts/` — Python experiment automation and plotting
- `experiments/` — Experiment configurations and results
- `docs/` — Research documentation

## Current Progress

- Basic OLSR simulation
- LET-based route switching experiment
- Automated experiment logging and PDR visualization
